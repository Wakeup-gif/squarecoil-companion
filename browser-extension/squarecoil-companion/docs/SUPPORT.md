# SquareCoil Companion Support

SquareCoil Companion works on the US Sign & Mill SquareCoil website. For help, open the Companion panel, go to **Settings → Help and diagnostics**, and choose **Submit a ticket** or **Send feedback**. You can also email `cristian@ussignandmill.com`.

Include the Companion version, what you tried, and what happened. The toolbar popup's **Technical details** section can copy current diagnostic status or download a local JSON history of recent technical events. The download works without a SquareCoil login. Review either file or text before sharing it; Companion does not send the diagnostic log automatically. Support and feedback open an email draft, which is sent only when you send it from your mail app. Please do not post customer names, job details, account credentials, backups, or timer exports in a public GitHub issue.

If a problem happens on your work PC, open the toolbar popup there and choose **Technical details → Download diagnostic log**. The download includes only events from the last 30 days; older entries are removed when Companion next runs or you download the log, not while Chrome is closed. Save the JSON file and share it with support only if you decide to. This technical log is separate from the Companion Full Backup, which contains your recorded work data and is used for data recovery.

For privacy details, read the [SquareCoil Companion Privacy Policy](PRIVACY-POLICY.md).
