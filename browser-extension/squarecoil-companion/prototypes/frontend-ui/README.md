# SquareCoil Companion Frontend Prototype

Standalone frontend/UI prototype adapted from the current SquareCoil Companion branch architecture.

Source branch baseline: `codex/implement-squarecoil-native-completion-observation`.

This folder is intentionally a UI/wiring prototype, not a production extension package. It models the trusted timer/read-model/authority boundaries without replacing the canonical extension runtime.

Open `index.html` in a browser to review the prototype.
