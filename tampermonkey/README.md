# Legacy Tampermonkey material

This directory contains historical userscripts and migration-era compatibility code for the US Sign/SquareCoil workflow. It is not the canonical Chrome/Edge extension source.

Use `browser-extension/squarecoil-companion/` for active Manifest V3 development. Treat versioned scripts in this directory as historical unless a maintainer explicitly identifies one as the supported compatibility script.

Place superseded duplicates and retired versions under `tampermonkey/archive/` with a short dated note. Do not add new extension behavior here.
